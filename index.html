User Guide & Panel Configurations

1. App Behavior Controls (Display Settings)

Configure how the assistant windows overlay interacting elements during your interview sessions:

  • Keep assistant always on top: Sets the Electron window configuration property to absolute foreground overlay. This keeps the tool instantly visible over browsers, fullscreen streaming panels, or IDEs.
  • Ask Electron to hide this window from screen capture: Enables native system level content protection parameters. Safe for use during real-time remote technical assessments.
  • Enable Transparency / Glassmorphism: Swaps out solid styling components for a modern, fluid semi-transparent look with soft edge blur properties.
  • Auto-scroll transcript panels: Instantly pushes viewport focus down to the latest processed speech block.

2. Engine Setup & Security Keys

Provide the backend processing channels and tokens required to compute context answers securely:

  • User Email Profile: Visual log displaying the authenticated active user profile structure.
  • Transcription Selection: Dropdown control allowing context swaps between system mic feeds and desktop application sound output channels.
  • Groq API Token Gateway: Private password-masked input framework where you securely input your custom API keys. Tokens are fully stored and persistent locally via electron-store.

3. Start Session

Select your preferred engine input option directly from your control tray → Click the Play icon to open data pipes.
